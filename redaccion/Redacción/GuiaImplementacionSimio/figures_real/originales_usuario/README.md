Simio que el usuario envio en el chat.

analisis, pero no quedaron expuestas como archivos locales descargables dentro
del workspace ni en las caches accesibles de Codex. Por eso no se pueden copiar
literalmente aqui sin que el usuario arrastre/exporte los PNG/JPG originales a
